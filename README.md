# 🎓 Smart College Attendance Tracker

A smart and user-friendly college attendance management application designed to help students manage their subjects, weekly timetables, daily attendance, and attendance percentages.

The application includes an intelligent Bunk Calculator, attendance prediction, recovery planner, and detailed attendance reports to help students maintain their required attendance percentage.

## 🚀 Features

### 1. Subject Management

* Add, edit, and delete subjects.
* Manage multiple subjects.
* Track total classes, attended classes, and absent classes.
* Maintain subject-wise attendance records.

### 2. Daily Attendance Management

* Mark attendance as Present or Absent.
* Automatically update attendance statistics.
* Store attendance history with date and subject.
* Edit incorrect attendance entries.
* Prevent duplicate attendance records.

### 3. Smart Attendance Calculator

* Set the minimum attendance requirement (e.g., 75%).
* Automatically calculate attendance percentage.
* Display Safe, Warning, and Critical attendance status.
* Calculate how many classes can safely be missed.
* Calculate how many classes are needed to recover attendance.

### 4. Smart Bunk Calculator

* Calculate the effect of missing upcoming classes.
* Predict attendance percentage after missing classes.
* Check whether attendance will remain above the required percentage.
* Help students make better attendance decisions.

### 5. Timetable Management

* Create a weekly college timetable.
* Add multiple classes for each day.
* Select subjects, starting times, and ending times.
* Edit, delete, and reschedule classes.
* Manage temporary timetable changes.
* Handle cancelled, postponed, and extra classes.

### 6. Automatic Daily Attendance

* Display today's classes automatically.
* Show subject names and class timings.
* Mark attendance with one click.
* Automatically update attendance statistics.
* Exclude cancelled classes from attendance calculations.

### 7. Attendance Prediction

* Predict attendance after attending upcoming classes.
* Calculate attendance after missing classes.
* Simulate different attendance situations.
* Display predicted attendance status.

### 8. Dashboard

* Overall attendance percentage.
* Total classes conducted.
* Total attended and absent classes.
* Number of subjects.
* Subjects with low attendance.
* Safe bunk count.
* Classes required to recover attendance.
* Subject-wise attendance progress bars.

### 9. Reports and History

* Daily attendance history.
* Subject-wise attendance reports.
* Monthly attendance summary.
* Semester attendance summary.
* Attendance charts.
* Present versus Absent statistics.

## 📊 Attendance Calculation

The application automatically calculates attendance using the following formula:

**Attendance Percentage**

```text
(Classes Attended / Total Classes Conducted) × 100
```

**Safe Bunk Calculation**

Calculates the maximum number of additional classes a student can miss while maintaining the required attendance percentage.

**Attendance Recovery Calculation**

Calculates the number of consecutive classes a student must attend to reach the required attendance percentage.
